## 3. Chromium Native Messaging Host Security Checks

- [ ] **3.1 32-Bit Frame Length Prefix Boundaries (TM-NMH-01)**
  - Verify `NativeFramingStream` enforces maximum frame size of 512 KiB (and hard 1 MiB Chromium limit).
  - Confirm frames with lengths exceeding 512 KiB are dropped immediately before buffer allocation.
  - Confirm negative or malformed 4-byte prefixes fail closed without process crashes or memory leaks.

- [ ] **3.2 Origin Validation & Zero-Wildcard Policy (TM-NMH-02)**
  - Verify `validateOrigin()` strictly enforces `chrome-extension://<32_char_alphanumeric_id>/`.
  - Confirm wildcards (`*`, `chrome-extension://*/*`) are rejected fail-closed.
  - Confirm non-Chromium schemes (`http://`, `file://`) are rejected.

- [ ] **3.3 Command Injection & Shell Denial (TM-NMH-04)**
  - Attempt to send operations requesting `run_command`, `exec`, or shell processes to `mediator-native-host.exe`.
  - Confirm all arbitrary command execution operations are rejected fail-closed.
  - Verify that executable packaging script rejects `.bat` and `.cmd` wrappers.

- [ ] **3.4 Clean User-Space Registration (TM-NMH-05)**
  - Verify registry scripts install exclusively to `HKCU` (Current User).
  - Confirm zero administrative elevation (UAC prompt) is requested or required.
  - Test clean uninstallation via `scripts/uninstall-windows.ps1` and verify full cleanup.

## 4. Sandbox Isolation & Network Severance Checks

- [ ] **4.1 Dedicated WSL2 Sandbox (`MediatorSandbox`)**
  - Verify untrusted code recipes run inside dedicated distribution `MediatorSandbox`, never the host default distribution (`Ubuntu`).
  - Verify Windows host drives (`/mnt/c`) are unmounted in `MediatorSandbox`.
  - Verify Windows command interop (`cmd.exe`, `powershell.exe`) is disabled in `/etc/wsl.conf`.

- [ ] **4.2 Network Namespace Isolation (`CLONE_NEWNET`)**
  - Verify execution takes place inside an isolated network namespace (`unshare --user --net`).
  - Confirm outbound IPv4 and IPv6 connections fail immediately (`ENETUNREACH`).
  - Confirm DNS queries and hypervisor DNS proxy (`10.255.255.254:53`) are unreachable.
  - Confirm child processes spawned by untrusted recipes cannot escape the network namespace.
